Bagian 1

Deskripsi

Pertemuan 4 menjawab di mana objek berada (Model → View → Projection). Pertemuan 5 menjawab bagaimana permukaan objek terlihat. Tiap vertex sekarang membawa position + normal + UV; fragment shader memakai ketiganya untuk texture sampling dan model pencahayaan Phong sederhana (ambient + diffuse + specular) per fragment.

Amati hubungan normal, texture, point light, camera, dan fragment shading. Detail modul: darlis-its.github.io/materi-grafika-komputer — Pertemuan 5, Praktikum.

  • Normal Matrix & normalisasi — u_normalMatrix (inverse-transpose) dan normalize(v_normal) di fragment shader; slider Non-uniform scale menunjukkan kenapa perlu.

  • Texture + filtering + wrapping — checkerboard programatik atau image (assets/texture.png); filtering NEAREST / LINEAR / LINEAR_MIPMAP; wrapping REPEAT / CLAMP_TO_EDGE (UV scale > 1 supaya kelihatan).
  • Camera-aware specular — Q/E menggeser camera di X, tombol Camera Orbit memutar camera mengelilingi objek.
  • Toggle & HUD — F flat/smooth, T texture, R reset; HUD menampilkan shading, light, texture, filtering, wrapping, dan camera.

Bagian 5

Penjelasan Objek

1. Kubus, Torus, Torus Knot, Bola

Semua bentuk dibangun sebagai deretan triangle non-indexed, jadi tiap bentuk punya dua set normal: flat (satu normal per triangle) dan smooth (satu normal per vertex). Posisi dan UV sama persis; yang berbeda hanya buffer normal yang di-bind lewat VAO. Pada kubus, normal smooth diambil dari arah pusat menuju sudut, sehingga kubus tampak membulat.

2. Normal & Normal Matrix

Normal harus ikut ditransformasikan, tapi bukan dengan Model Matrix biasa. Saat non-uniform scale (mis. X=1.8, Y=0.6), normal yang dikali Model Matrix tidak lagi tegak lurus permukaan. u_normalMatrix (inverse-transpose bagian 3×3 Model Matrix) memperbaikinya, lalu normalize() di fragment shader mengembalikan panjang vector ke 1.

3. Point Light & Camera

Light digambar sebagai kubus kecil tanpa lighting di posisinya. L = normalize(lightPos - worldPos) menentukan diffuse; V = normalize(cameraPos - worldPos) menentukan specular, sehingga highlight ikut bergeser ketika camera bergerak walau light diam.

4. Texture, Filtering, Wrapping

Texture dipakai sebagai base color lalu dikali kontribusi cahaya. NEAREST terlihat tajam/pixelated, LINEAR memperhalus, LINEAR_MIPMAP memakai mipmap saat texture terlihat jauh. Wrapping baru terlihat jika UV keluar 0–1, makanya ada slider UV Scale: REPEAT mengulang pola, CLAMP_TO_EDGE menarik piksel tepi.

Bagian 6

Cuplikan GLSL (WebGL2, ES 3.00)

Vertex Shader — transform posisi & normal, teruskan world position dan UV:

#version 300 es in vec3 a_position; in vec3 a_normal; in vec2 a_texCoord; uniform mat4 u_model; uniform mat4 u_view; uniform mat4 u_projection; uniform mat3 u_normalMatrix; uniform float u_uvScale; out vec3 v_worldPosition; out vec3 v_normal; out vec2 v_texCoord; void main() { vec4 worldPosition = u_model * vec4(a_position, 1.0); v_worldPosition = worldPosition.xyz; v_normal = u_normalMatrix * a_normal; v_texCoord = a_texCoord * u_uvScale; gl_Position = u_projection * u_view * worldPosition; }

Fragment Shader — texture sebagai base color, lalu ambient + diffuse + specular:

vec3 N = normalize(v_normal); vec3 L = normalize(u_lightPosition - v_worldPosition); vec3 V = normalize(u_cameraPosition - v_worldPosition); float diff = max(dot(N, L), 0.0); vec3 R = reflect(-L, N); float spec = (diff > 0.0) ? pow(max(dot(R, V), 0.0), u_shininess) : 0.0; vec3 base = texture(u_texture, v_texCoord).rgb; vec3 ambient = u_ambientStrength * base; vec3 diffuse = diff * u_lightColor * base; vec3 specular = spec * u_lightColor; outColor = vec4(ambient + diffuse + specular, 1.0);
Bagian 7

Ringkasan

Praktikum ini mengubah objek 3D Pertemuan 4 menjadi permukaan dengan informasi visual lebih kaya: position menentukan di mana permukaan, normal menentukan ke mana permukaan menghadap, UV menentukan bagian texture yang dipakai, lighting menentukan bagaimana cahaya memengaruhi permukaan, dan texture memberi detail dasar tanpa menambah triangle. Semuanya dijalankan di satu shader program dan menjadi penutup rangkaian WebGL low-level sebelum Introduction to Three.js.
